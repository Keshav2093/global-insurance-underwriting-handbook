# Proposal & Application Forms

Standard proposal and application forms used in underwriting. These templates support consistent, comprehensive information gathering for risk assessment.

## Forms

| Form | Purpose |
|------|---------|
| [General Insurance Proposal](01-general-proposal.md) | Core information for any P&C line |
| [Commercial Property Proposal](02-commercial-property.md) | Buildings, values, protection details |
| [Commercial General Liability Proposal](03-general-liability.md) | Operations, products, contractual exposures |
| [Workers Compensation Proposal](04-workers-comp.md) | Payroll, classifications, loss history |
| [Fleet / Commercial Auto Proposal](05-commercial-auto.md) | Vehicles, drivers, operations |
| [Supplemental Risk Questionnaire](06-supplemental-questionnaire.md) | High-risk or complex exposures |

## Completion Guidelines

| Requirement | Description |
|-------------|-------------|
| **Full disclosure** | All questions answered; no blanks |
| **Accuracy** | Information must be true and current |
| **Signatures** | Signed by authorized party |
| **Supporting data** | Attach loss runs, financials, surveys |
| **Timeliness** | Submit before effective date |
| **Declaration** | Misrepresentation voids coverage |

## Common Sections

| Section | Information Gathered |
|---------|----------------------|
| General information | Insured, addresses, contacts |
| Risk details | Description, locations |
| Coverage requested | Limits, deductibles, endorsements |
| Loss history | Prior claims, losses |
| Protection | Loss prevention features |
| Financial | Credit, financial statements |
| Declarations | Signature, truthfulness, authority |
