# 6.3 Endorsements & Mid-term Changes

## Overview

An **endorsement** is a written modification to the insurance contract during the policy period. Endorsements keep the policy aligned with the insured's actual risk as circumstances change. Incorrect or missing endorsements are a leading source of coverage disputes.

## Types of Mid-term Changes

| Type | Examples |
|---|---|
| **Exposure change** | Add/remove vehicle, location, employee |
| **Coverage change** | Increase/decrease limits, add coverage |
| **Value change** | Change insured values, SOV update |
| **Named insured change** | Entity, name, address |
| **Deductible change** | Increase/decrease retention |
| **Forms change** | Add/remove endorsements |
| **Payment change** | Payment plan, billing information |
| **Policyholder service** | Certificate requests, evidence |

## Endorsement Process

```
1. Receive request (insured/producer; verify authority)
2. Review terms and conditions (eligible? within authority?)
3. Re-rate / re-underwrite if required
4. Apply the endorsement with effective date
5. Calculate premium adjustment (AP/RP)
6. Issue amended documents
7. Deliver and record
```

## Effective Date Handling

| Situation | Rule |
|---|---|
| **Prospective** | Endorsement effective from a future date |
| **Retroactive** | Effective before the current date; requires authorization and consideration |
| **Backdated binders** | Coverage may be retroactive from a binder; must align |
| **Loss in progress** | No coverage for known losses; clarify at effective date |

## Premium Adjustments

- **Additional premium (AP)** — when exposure or limits increase.
- **Return premium (RP)** — when exposure or limits decrease.
- Adjustments are **pro-rata** by time unless short-rate applies.
- AP/RP must be **transparent** and documented on the endorsement.

| Change | Effect |
|---|---|
| Add vehicle | AP from the effective date |
| Remove driver | RP from the effective date |
| Increase limits | AP; ILF difference |
| Reduce coverage | RP; pro-rata |
| Change deductible | AP or RP per rate difference |

## Underwriting Referral

Some changes require underwriting review:

- **Specialty lines** — adding high-hazard exposures.
- **Large value increases** — property or liability.
- **Change of occupancy** — different class.
- **Named insured changes** — new legal entity.
- **Changes outside guidelines** — discretionary authority.

## Documentation Requirements

Each endorsement must show:

| Element | Example |
|---|---|
| Endorsement number | Endt. 2 |
| Policy number | CP-1001234 |
| Effective date | 03/01/2026 |
| Named insured | ABC Manufacturing Inc. |
| Description of change | Added forklift; $25,000 AP |
| Forms referenced | CP 12 18 – Coverage change |
| Issued by/e-signature | System/user |

## Common Endorsement Errors

| Error | Impact |
|---|---|
| Wrong effective date | Coverage gap or retroactive exposure |
| Incorrect limit | Claim underpaid or uninsured exposure |
| Missing endorsement | Policy doesn't match expectation at claim |
| Wrong form edition | Legal interpretation issues |
| AP/RP error | Premium dispute; audit finding |
| No signature/authority | Unauthorized change |

## Endorsement vs. New Policy

| Situation | Endorsement | New Policy |
|---|---|---|
| Add a vehicle | Yes | No |
| Change ownership entity | Possibly (review) | Possibly |
| Major restructuring | No | Yes |
| End of policy period change | Renewal | Yes |
| Change carrier | No | Yes |

## Summary

- Endorsements **modify the contract** mid-term; accuracy is critical.
- **Effective dates, premium adjustments, and documentation** must be precise.
- **Underwriting referral** applies to material changes.
- **AP/RP calculations** must be transparent and correct.
- Errors produce **coverage disputes and premium issues**.
