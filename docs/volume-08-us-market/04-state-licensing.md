# 8.4 Licensing & Admissions

## Overview

**Licensing** is the state's gatekeeper for insurers and intermediaries. Insurers must be **admitted** (licensed) to transact business in a state; producers must be **licensed** to sell, solicit, or negotiate insurance. Licensing protects consumers and enforces state standards.

## Insurer Licensing (Admission)

An insurer seeking to write business in a state applies for a **Certificate of Authority**.

| Requirement | Description |
|---|---|
| **Incorporation** | Organized under a state or foreign jurisdiction |
| **Capital & surplus** | Minimum statutory capital and surplus |
| **Business plan** | Lines of business, territory, operations |
| **Officers & directors** | Financial and character scrutiny |
| **Reinsurance** | Security for ceded business |
| **Examination** | Pre-licensing financial review |
| **Fees** | Licensing and filing fees |

Once admitted, the insurer may write **admitted business** — subject to rate and form regulation and **guaranty fund** protection.

## Types of Admission

| Type | Description |
|---|---|
| **Domestic** | Incorporated in the state |
| **Foreign** | Incorporated in another US state |
| **Alien** | Incorporated outside the US; must meet additional security requirements |

## Producer Licensing

| Role | License |
|---|---|
| **Agent** | Represents an insurer; licenses for lines sold |
| **Broker** | Represents the insured; places coverage |
| **MGA/MGU** | Binds and services under authority from insurers |
| **Adjuster** | Independent or public adjuster licensing |
| **Surplus lines broker** | Places non-admitted coverage |

### Producer Requirements

| Requirement | Description |
|---|---|
| **Pre-licensing education** | Coursework per state |
| **Examination** | State licensing exam per line |
| **Continuing education** | Ongoing CE credits |
| **Background** | Criminal and financial history review |
| **Appointment** | Insurer must appoint the producer |
| **Fees** | License and renewal fees |

### Reciprocity

- **NIPR** (National Insurance Producer Registry) enables multistate licensing.
- **Reciprocity agreements** allow producers licensed in one state to be licensed in others.
- **Non-resident licenses** are typically reciprocal.

## Delegated Underwriting Authority (MGA)

| Control | Purpose |
|---|---|
| **Written agreement** | Authority documented and approved |
| **Financial requirements** | MGAs may need fidelity coverage |
| **Reporting** | Premium, claims, and policy reporting |
| **Underwriting guidelines** | Authority within stated limits |
| **Review** | Periodic audits of authority use |

MGA authority is **regulated** — states have model acts controlling delegation.

## Surplus Lines

| Element | Rule |
|---|---|
| **Non-admitted insurer** | Not licensed in the state |
| **Diligent effort** | Broker must show the risk cannot be placed in the admitted market |
| **Surplus lines broker license** | Required to place coverage |
| **Taxes** | Surplus lines premium tax to the home state |
| **Eligibility** | Insurer must be eligible per state lists |

Surplus lines are **not protected by the state guaranty fund**.

## Insurance Company Licensing in Practice

```
1. Prepare application (business plan, financial statements)
2. Submit to state insurance department
3. Department review (financial, management, plan)
4. Public notice and hearing (where required)
5. Grant Certificate of Authority
6. Ongoing compliance (filings, exams, reporting)
```

## Compliance After Licensing

| Obligation | Practice |
|---|---|
| **Annual statement** | Financial reporting to all states |
| **Rate/form filings** | Maintain approvals |
| **Market conduct** | Pass examinations |
| **Producer appointments** | Maintain records |
| **Continuing education** | Producer CE compliance |
| **Surplus lines reports** | Where applicable |

## Discipline and Enforcement

| Action | Example |
|---|---|
| **Fine** | Penalty for violations |
| **License suspension** | Temporary revocation |
| **License revocation** | Loss of authority to transact |
| **Cease and desist** | Stop a specific practice |
| **Conservatorship** | State takes control of an impaired insurer |

## Summary

- **Insurers** are admitted per state; **producers** are licensed per state.
- **Capital, plans, exams, and character** underpin admission.
- **Reciprocity and NIPR** streamline producer licensing.
- **MGA authority** is regulated with written agreements and audits.
- **Surplus lines** provide a non-admitted alternative with separate rules.
- **Continuing compliance** — filings, exams, appointments, CE.
