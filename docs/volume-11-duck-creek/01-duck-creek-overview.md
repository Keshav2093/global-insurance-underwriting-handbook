# 11.1 — Duck Creek Overview

## 11.1.1 Company History

| Year | Milestone |
|------|-----------|
| 2000 | Founded as Duck Creek Technologies in Kensington, Maryland |
| 2003 | Released initial policy administration platform |
| 2006 | Introduced software-as-a-service (SaaS) delivery model |
| 2009 | Named a leader in P&C policy administration by Gartner |
| 2011 | Released Duck Creek Billing |
| 2014 | Released Duck Creek Claims |
| 2017 | Launched Duck Creek on Microsoft Azure |
| 2019 | IPO on Nasdaq (DCT) |
| 2021 | Acquired by Apax Partners for $2.4 billion |
| 2023 | Launched Duck Creek Distribution Management and reinsurance analytics |
| 2025 | Continued expansion of AI-based suite (Duck Creek Copilot) |

## 11.1.2 What Is Duck Creek?

**Duck Creek** is a cloud-native, SaaS platform for property & casualty insurers. It provides the core systems of record for policy administration, billing, and claims, plus data, analytics, and distribution management capabilities.

### Core Value Proposition

| Attribute | Duck Creek |
|-----------|-----------|
| **Delivery model** | SaaS, hosted on Microsoft Azure |
| **Architecture** | Cloud-native microservices |
| **Configuration** | Product definitions fully configurable, no code |
| **AI/ML** | Embedded AI throughout product suite |
| **Data** | Duck Creek Insight = analytics/data platform |
| **Market focus** | P&C insurance (all lines) |
| **Customers** | 100+ insurers globally |

## 11.1.3 Duck Creek Product Suite

### Duck Creek Applications

| Application | Function | Equivalent |

| **Duck Creek Author** | Policy administration, product configuration | Guidewire PolicyCenter |

| Component | Description |

## 11.1.4 Duck Creek vs. Guidewire

| Dimension | Duck Creek | Guidewire |
|-----------|-----------|-----------|
| **Cloud** | Microsoft Azure | AWS |
| **Language** | .NET (C#) based | Java / Gosu |
| **Configuration** | ProductIX, configurable rules | Studio, Gosu |
| **Release model** | SaaS, frequent releases | Annual major releases, quarterly minors |
| **Policy center** | Duck Creek Author | PolicyCenter |
| **Billing center** | Duck Creek Billing | BillingCenter |
| **Claims center** | Duck Creek Claims | ClaimCenter |
| **Data/analytics** | Duck Creek Insight | Guidewire Data Platform / InfoCenter |
| **AI** | Duck Creek Copilot, Luminos | Guidewire AI + Polaris |
| **Typical customer** | Mid-market, regional, digital-first | Large, global insurers |

## Key Takeaways

1. **Duck Creek is a cloud-native SaaS platform** built on Microsoft Azure.
2. **The platform covers the full insurance value chain** — policy, billing, claims, data, distribution, reinsurance.
3. **Configuration-first approach** — products are defined in ProductIX without coding.
4. **API-first architecture** enables partner integration and digital channels.
5. **Duck Creek targets P&C insurers** with a focus on speed to market and lower cost of ownership.
