Volume 11 covers Duck Creek Technologies — a leading SaaS provider of insurance core systems. It explains the Duck Creek platform, product suite, architecture, and implementation approach.

## Learning Objectives

After completing this volume you should be able to:

1. Explain the Duck Creek platform and its modules.
2. Describe Duck Creek Author policy administration and product configuration.
3. Describe Duck Creek Billing workflows.
4. Describe Duck Creek Claims handling.
5. Use Duck Creek data and analytics tools.
6. Plan Duck Creek implementation and integrations.
7. Distinguish configuration from customization in Duck Creek.
