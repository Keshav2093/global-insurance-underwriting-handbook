## Key Checks

| Step | Check | Pass Criteria |
|------|-------|---------------|
| 1 | Operations described | Class codes match actual operations |
| 2 | Appetite | Operations within stated appetite |
| 3 | Loss history | No concerning frequency / severity |
| 4 | Products exposure | Products liability evaluated |
| 5 | Contractual exposure | Contracts reviewed for additional insured requirements |
| 6 | Limits adequacy | Limits appropriate to exposure |
| 7 | Claim patterns | No upward trend or recurring issues |

## Liability Considerations

### Occupancy / Operations

| Operations | Decision |
|------------|----------|
| Preferred (office, retail, wholesale) | Accept |
| Moderate (light manufacturing, restaurants) | Accept with condition |
| High risk (construction, contractors) | Refer / condition |
| Restricted (chemical, explosives, amusement) | Decline / specialty |

### Loss History

| Metric | Action |
|--------|--------|
| Claims trend increasing | Refer / rate heavily |
| Recurring cause | Condition: safety plan, engineering |
| Large single claim | One-off event if controls improved |
| No losses | Accept if risk profile stable |

### Products / Completed Operations

| Element | Action |
|---------|--------|
| Quality control program | Verify exists |
| Product recall history | Refer if any |
| Contractual product liability | Review indemnity terms |
| Long-tail exposure | Consider claims-made form |

---

## Conditions by Risk Factor

| Risk Factor | Condition |
|-------------|-----------|
| Contractor without safety plan | Written safety program, E-Mod review |
| Subcontractors uninsured | Certificates of insurance required |
| Liquor operations | Server training, dram shop review |
| Products manufacturer | Quality control documentation |
| Higher hazard | Higher deductible / SIR |
| Employee turnover high | Training documentation required |

---

## Referral Triggers

| Trigger | Action |
|---------|--------|
| Contractor E-Mod above 1.30 | Refer to senior UW |
| Pattern of claims | Refer for experience review |
| Multi-million dollar limits | Refer to capacity / reinsurance |
| New product exposure | Refer to product manager |
| Claims-made conversion | Refer per guidelines |

---

## Outcomes

| Outcome | Conditions | Notes |
|---------|-----------|-------|
| **Accept** | None | Standard risk profile |
| **Accept with conditions** | Listed | Safety, training, certificates |
| **Refer** | Senior UW approval | Outside standard guidelines |
| **Decline** | N/A | Document reasoning |
