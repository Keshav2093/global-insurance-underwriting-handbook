# General Referral Decision Tree

Used to determine whether a submission can be accepted within authority or requires referral.

---

---

## Key Decision Points

| Step | Question | If YES | If NO |
|------|----------|--------|-------|
| 1 | Risk within appetite? | Continue | Consider decline / refer |
| 2 | All documents complete? | Continue | Request more information |
| 3 | Risk within authority? | Continue within guidelines | Refer to senior UW |
| 4 | Any outstanding conditions? | No — accept | Yes — defer decision |
| 5 | Risk complexity normal? | Accept | Refer for review |

## Referral Criteria

### Automatic Referral

| Criteria | Description |
|----------|-------------|
| **New line of business** | Not covered by existing focus |
| **Aggregate exceeded** | Policy limits above authority |
| **Catastrophe exposure** | PML above threshold |
| **High-risk occupancies** | Listed in restricted classes |
| **Financial instability** | Material financial concerns |
| **Litigation trend** | Significant liability claim patterns |
| **Capacity constraints** | Limit requirements above treaty capacity |
| **First party claims issues** | Fraud indicators, litigation history |

### Discretionary Referral

| Criteria | Description |
|----------|-------------|
| **Unusual risk** | Profile not covered by standard guidelines |
| **Unusual terms** | Coverage wording beyond standard forms |
| **Product concern** | Emerging product liability issues |
| **Market concern** | Competitive or regulatory pressure |
| **Any uncertainty** | When in doubt, escalate |

## Conditions Requiring Approval

| Condition | Approval Level |
|-----------|----------------|
| Waive standard deductible | Senior UW |
| Relieve coinsurance | Property manager |
| Expand coverage territory | Product manager |
| Override rate | Pricing committee |
| Accept above authority limit | Senior UW / committee |

---

## Decision Outcomes

| Outcome | Conditions | Documentation Required |
|---------|-----------|------------------------|
| **Accept** | None | Sign-off, file note |
| **Accept with conditions** | Listed in file | Conditions communicated |
| **Refer** | Approved by senior UW | Referral form, decision recorded |
| **Decline** | N/A | Decline rationale, file note |

---

## Principles

| Principle | Description |
|-----------|-------------|
| **Appetite first** | No out-of-appetite submissions without referral |
| **Authority respected** | Decisions within delegated authority only |
| **Documentation** | Every referral and decision recorded |
| **Timeliness** | Refer early to avoid coverage gaps |
| **Transparency** | Referral rationale shared with producer |
