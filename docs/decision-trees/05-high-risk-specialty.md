## High-Risk Classes

| Class | Typical Facility / Review |
|-------|---------------------------|
| Fireworks / explosives | Specialty / restricted |
| Chemical manufacturing | Environmental & property specialty |
| Aviation / marine | Dedicated facilities |
| Waste disposal / transfer | Environmental specialty |
| Nightclubs / bars | Entertainment / liquor liability specialty |
| Security / armored car | Commercial specialty |
| Assisted living / nursing | Healthcare liability specialty |
| Daycare | Childcare liability specialty |
| Horse boarding / equestrian | Equestrian specialty |
| Underground storage tanks | Environmental specialty |
| Oil & gas | Energy specialty |
| Cannabis | Regulated specialty program |
| Blockchain / crypto | Cyber / fintech specialty |

---

## Specialty Assessment Areas

| Area | Assessment |
|------|-----------|
| **Expertise** | Dedicated specialist underwriter / facility |
| **Hazard identification** | Complete hazard profile |
| **Engineering review** | Survey where required |
| **Safety management** | Confirmed loss control program |
| **Claims experience** | Facility loss history and trends |
| **Capacity** | Facility limits and reinsurance |
| **Pricing** | Specialty rates and minimums |
| **Regulatory** | Licensing, permits, compliance |
| **Financial strength** | Insured and facility stability |

---

## Survey Requirements

| Trigger | Survey Type |
|---------|-------------|
| High-hazard operations | Full engineering survey |
| Large property values | Property valuation / engineering |
| Process risks | Process safety review |
| Environmental exposure | Phase I / II environmental |
| New construction | Construction / occupancy review |
| Catastrophe zones | Catastrophe engineering review |

---

## Referral Criteria

| Criteria | Action |
|----------|--------|
| No specialty facility available | Refer out / alternate market |
| Hazard beyond facility appetite | Decline within guidelines |
| Missing engineering reports | Condition: survey before binding |
| Capacity insufficient | Refer to reinsurance |
| Regulatory concerns | Refer to compliance |

---

## Conditions

| Condition | Purpose |
|-----------|---------|
| Survey before inception | Verify risk attributes |
| Loss prevention program | Reduce hazard |
| Regulatory compliance | Confirm permits |
| Loss control recommendations | Mitigation actions |
| Higher deductible / SIR | Align risk retention |
| Sub-limits / exclusions | Control coverage scope |
| Claims-made form | Manage long-tail exposure |

---

## Outcomes

| Outcome | Conditions | Notes |
|---------|-----------|-------|
| **Accept** | Within facility | Hazard assessed, capacity available |
| **Accept with conditions** | Listed | Survey / mitigation / compliance |
| **Refer** | Senior or specialty approval | Outside standard appetite |
| **Decline** | N/A | No facility / unacceptable risk |
