# Underwriting Decision Trees

Structured decision trees to support consistent, efficient underwriting decisions. Each tree walks through key questions to reach a decision: accept, refer, condition, or decline.

## Trees

| Tree | Use |
|------|-----|
| [General Referral Tree](01-general-referral.md) | When to accept, refer, or decline a submission |
| [Property Risk Tree](02-property-risk.md) | Property underwriting decision flow |
| [Liability Risk Tree](03-liability-risk.md) | General liability decision flow |
| [Fraud / Red Flag Tree](04-fraud-red-flags.md) | Identify potential misrepresentation / fraud |
| [High-Risk & Specialty Tree](05-high-risk-specialty.md) | Specialized and complex exposures |

## How to Use

| Step | Action |
|------|--------|
| 1 | Start at the top of the relevant tree |
| 2 | Answer each question based on file information |
| 3 | Follow the branching logic |
| 4 | Record the outcome and reasoning |
| 5 | Document any conditions applied |

## Principles

| Principle | Description |
|-----------|-------------|
| **Consistency** | Same facts lead to same decisions |
| **Guardrails** | Trees set clear boundaries on discretion |
| **Documentation** | Every outcome recorded with rationale |
| **Referral** | Escalate when outside authority or guidelines |
| **Override** | Departure from tree requires senior UW approval |
