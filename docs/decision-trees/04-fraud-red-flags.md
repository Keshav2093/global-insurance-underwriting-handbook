# Fraud / Red Flag Decision Tree

Used to identify potential misrepresentation, nondisclosure, or fraud in applications and claims.

---

## Application Red Flags

| Flag | Concern | Action |
|------|---------|--------|
| **Rapid application** | Pressuring to bind without review | Require full verification |
| **Incomplete answers** | Omission of key facts | Request completion / decline |
| **Inconsistent info** | Discrepancies between forms | Investigate differences |
| **New business + no history** | Lack of insurability evidence | Credit check, financials |
| **Frequent carrier changes** | "Insurance shopping" pattern | Obtain prior loss runs |
| **Unusual limits** | Coverage not matching exposure | Verify values |
| **Vague operations** | Unclear business description | Request detail |
| **Multiple reinstatements** | Indicates claim history | Full loss history |
| **P.O. box only** | No physical location | Verify physical address |
| **Cash transactions** | Financial opacity | Financial statements |
| **Pressure tactics** | Urgency to bind | Do not rush process |

## Claim Red Flags

| Flag | Concern |
|------|---------|
| **Claim immediately after inception** | Possible contrived loss |
| **Claim value exceeds policy limits** | Possible inflation |
| **Inconsistent incident details** | Fabrication indicators |
| **No witnesses** | Unable to corroborate |
| **Delayed reporting** | Late notice suspicion |
| **Prior similar claims** | Pattern / fraud |
| **Request for cash payment** | Avoidance of records |
| **Pressure to settle quickly** | Hidden issues |
| **Discrepant documentation** | Altered records |
| **Insurance recently increased** | Pre-planned loss |

---

## Verification Actions

| Action | Purpose |
|--------|---------|
| **MVR check** | Verify driving history for auto |
| **Credit check** | Assess financial reliability |
| **Financial statements** | Verify income / business |
| **Prior loss runs** | Confirm claims history |
| **Physical inspection** | Verify property condition |
| **Third-party databases** | Check undisclosed claims / history |
| **GIS / aerial imagery** | Verify property location / features |
| **Social media review** | Identify undisclosed activities |

---

## Escalation

| Level | Action |
|-------|--------|
| **Minor concern** | Document; monitor and verify |
| **Material concern** | Refer to senior underwriter |
| **Fraud suspicion** | Refer to Special Investigations Unit (SIU) |
| **Confirmed fraud** | Decline / void coverage; report as required |

## Principles

| Principle | Description |
|-----------|-------------|
| **Fairness** | Red flags verified before action |
| **Timeliness** | Investigate promptly |
| **Confidentiality** | Findings handled discreetly |
| **Compliance** | Follow regulatory reporting obligations |
| **Documentation** | Written record of the full process |
