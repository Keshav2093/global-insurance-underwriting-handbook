## Key Checks

| Step | Check | Pass Criteria |
|------|-------|---------------|
| 1 | Description complete | Addresses, construction, occupancy, values |
| 2 | Values adequate | Replacement cost current & supported |
| 3 | Guidelines met | Construction / occupancy within appetite |
| 4 | Loss history | No unacceptable frequency / severity |
| 5 | Catastrophe exposure | Within PML / per-risk limits |
| 6 | Protection | Fire protection and loss control adequate |
| 7 | Vacancy | Not vacant beyond acceptable period |

## Property Decision Matrix

### Construction Type

| Construction | Decision |
|--------------|----------|
| Fire-resistive | Accept |
| Masonry / non-combustible | Accept |
| Frame / wood | Accept with rate; refer if high value |
| Mixed | Review dominant construction |

### Occupancy

| Occupancy | Decision |
|-----------|----------|
| Preferred (office, retail, warehouse) | Accept |
| Moderate (manufacturing, food processing) | Accept with condition |
| High risk (chemical, woodworking, etc.) | Refer / condition |
| Restricted (explosives, high-hazard) | Decline / specialty facility |

### Protection Class

| Protection | Decision |
|------------|----------|
| Class 1–4 | Accept |
| Class 5–8 | Rate adequately; review distance |
| Class 9–10 | Refer / decline unless superior protection |

---

## Conditions by Risk Factor

| Risk Factor | Condition |
|-------------|-----------|
| Older roof | Replace within 12 months or apply roof exclusion |
| Deferred maintenance | Engineering survey, repair plan |
| No sprinklers (larger risk) | Install sprinklers or refer |
| High-value contents | Verify replacement cost schedule |
| Business income exposure | Confirm coverage need and adequacy |
| Vacant | Vacant building status, higher rate |
| Catastrophe zone | Percentage deductible, sub-limits |

---

## Referral Triggers

| Trigger | Action |
|---------|--------|
| Value above authority | Refer to senior UW |
| PML above threshold | Refer to reinsurance |
| Exceptional construction | Refer for specialist review |
| Coinsurance relief requested | Refer to product |
| Condominium / special entity | Refer per guidelines |
| Utility / power plant exposure | Refer to specialty |
| Green / sustainable construction | Refer for valuation |

---

## Outcomes

| Outcome | Conditions | Notes |
|---------|-----------|-------|
| **Accept** | None | Within all guidelines |
| **Accept with conditions** | Listed | Protective measures / repairs |
| **Refer** | Senior UW approval | Outside standard guidelines |
| **Decline** | N/A | Document reasoning |
