# Underwriting Checklists

Practical underwriting checklists for common P&C lines. These are working tools use to structure submission review, ensure nothing is missed, and document the decision.

## Checklists

| Checklist | Purpose |
|-----------|---------|
| [General Submission Review](01-general-submission.md) | Core checks for any new submission |
| [Personal Auto](02-personal-auto.md) | Vehicle, driver, and coverage checks |
| [Homeowners](03-homeowners.md) | Property, occupancy, and protection checks |
| [Commercial Property](04-commercial-property.md) | Buildings, occupancy, and loss prevention |
| [Commercial General Liability](05-general-liability.md) | Operations, exposures, and products |
| [Workers Compensation](06-workers-comp.md) | Classification, experience, and controls |
| [Renewal Review](07-renewal-review.md) | Renewal-specific checks and changes |
| [Endorsement Review](08-endorsement-review.md) | Mid-term change evaluation |

## How to Use

1. **Pre-submission** — Review for completeness before engaging.
2. **During review** — Work through the checklist systematically.
3. **Decision** — Record answers, rationale, and any conditions.
4. **Documentation** — Keep the completed checklist in the file.
5. **Decline/Refer** — Escalate per authority matrix.

## General Principles

| Principle | Description |
|-----------|-------------|
| **Consistency** | Same criteria for all submissions |
| **Documentation** | Record why decisions were made |
| **Authority** | Do not exceed binding authority |
| **Fairness** | No discrimination on protected grounds |
| **Compliance** | Follow guidelines, regulations, and market agreements |
| **Conditions** | Clearly state any conditions or requirements |
