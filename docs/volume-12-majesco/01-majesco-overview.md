## 12.1.2 What Is Majesco?

**Majesco** is a leading provider of core insurance systems for **P&C and Life & Annuities (L&A)**. It delivers cloud-native, API-first platforms for policy administration, billing, claims, distribution, and data analytics.

### Core Value Proposition

| Attribute | Majesco |
|-----------|---------|
| **Delivery model** | Cloud-native SaaS or licensed |
| **Architecture** | Microservices, API-first |
| **Coverage** | P&C + Life & Annuities |
| **Configuration** | Model-based, configurable from user interface |
| **AI/ML** | Embedded analytics and decisioning |
| **Customers** | 600+ insurance companies |
| **Policies** | 100+ million policies administered |

## 12.1.5 Majesco Cloud

### CloudInsurer Platform

**CloudInsurer** is Majesco's cloud-native platform, running on Microsoft Azure with:

| Layer | Description |
|-------|-------------|
| **Infrastructure** | Azure IaaS/PaaS |
| **Platform services** | Microservices, APIs, event streaming |
| **Application suite** | Policy, Billing, Claims, Distribution, Analytics |
| **Data platform** | Azure SQL, Data Lake, Power BI |
| **Security** | Azure AD, Key Vault, Defender |
| **DevOps** | Azure DevOps, CI/CD automation |

### Cloud Advantages

| Advantage | Description |
|-----------|-------------|
| **SaaS speed** | Rapid deployment, no infrastructure |
| **Scenario-based** | Select (P&C), Config (moderate), Full Build (custom) |
| **Automatic upgrades** | Platform maintained by Majesco |
| **Scalability** | Auto-scale for peak volumes |
| **Multi-tenant** | Secure tenant isolation |
| **Integration** | API-first, event-driven |

## Key Takeaways

1. **Majesco serves both P&C and Life & Annuities** insurers.
2. **CloudInsurer** is the cloud-native SaaS platform on Azure.
3. **The product suite** covers policy, billing, claims, distribution, and analytics.
4. **Configuration** is model-based and UI-driven, minimizing code.
5. **600+ customers** with 100M+ policies demonstrates scale.
