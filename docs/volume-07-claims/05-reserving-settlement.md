# 7.5 Reserving & Settlement

## Overview

**Reserving** estimates the future cost of each claim; **settlement** converts that estimate into actual payment. Accurate reserves are essential for financial reporting, pricing, and management decisions.

## Case Reserves

The **case reserve** is the estimate of what the claim will ultimately cost, including:

| Component | Description |
|---|---|
| **Indemnity** | Payment to or for the insured/claimant |
| **Defense costs** | Legal fees and expenses |
| **Allocated loss expense (ALAE)** | Expert, investigation, medical costs |
| **Interest/penalties** | Potential statutory charges |
| **Salvage/subrogation** | Expected recoveries (net down if certain) |

## Reserve Setting

| Principle | Practice |
|---|---|
| **Best estimate** | Most likely ultimate cost, not minimum or maximum |
| **Timely** | Set at first evaluation; update as facts emerge |
| **Consistent** | Same methodology across the claim |
| **Reviewed** | Regular reserve adequacy reviews |
| **Documented** | Basis of the estimate recorded |

## Reserve Ranges and Categories

| Category | Meaning |
|---|---|
| **Initial reserve** | Set from FNOL and first investigation |
| **Minimum/maximum** | Range of possible outcomes |
| **Most likely** | Point estimate used for the case reserve |
| **Incurred but not reported (IBNR)** | Actuarial estimate for unreported claims (not the adjuster's case reserve) |

## Reserve Adequacy

| Signal | Meaning |
|---|---|
| **Settlements vs. reserves** | Actual payments above or below case reserves |
| **Aging of open claims** | Claims not closing; reserves may be stale |
| **Large loss reviews** | Periodic reassessment of high-severity claims |
| **Actuarial analysis** | Compare case + IBNR to ultimate estimates |

## Payments

| Payment Type | Example |
|---|---|
| **Advance** | Early payment for medical or emergency needs |
| **Interim** | Partial payment while claim continues |
| **Final** | Full settlement with release |
| **Defense payments** | Panel counsel and expert invoices |
| **Structured** | Periodic payments over time |

## Settlement Mechanics

```
1. Value the claim (reserve review)
2. Obtain settlement authority
3. Negotiate to agreement
4. Prepare release and settlement documents
5. Issue payment to correct parties
6. Record and close reserve
7. Recover (subrogation/reinsurance) if applicable
```

## Payment Controls

| Control | Purpose |
|---|---|
| **Payee verification** | Correct claimant, insured, attorney, provider |
| **Authority threshold** | Payment within delegated authority |
| **Two-party checks** | Where required (insured + lender) |
| **Duplicate payment checks** | No double payment |
| **Approval workflow** | Large payments reviewed |
| **Documentation** | Release, proof, file record |

## Release Types

| Type | Scope |
|---|---|
| **General release** | Claimant releases all claims related to the incident |
| **Indemnity agreement** | Protects insured/insurer from future claims |
| **Compromise release** | Settlement of disputed claim |
| **Release of subrogation** | Waives insurer's right to recover |
| **Structured settlement documents** | Payout terms, annuity |

## Reserve and Settlement Review

| Review | Frequency |
|---|---|
| **Initial reserve** | At claim setup |
| **Periodic review** | With investigation updates |
| **Large loss** | Monthly/weekly for high-severity |
| **Pre-settlement** | Final adequacy check |
| **Post-closure audit** | Compare actual vs. reserved |

## Summary

- **Reserves** estimate ultimate cost; **settlement** realizes it.
- Reserves include **indemnity, defense, ALAE, and net recoveries**.
- **Authority, documentation, and controls** govern payments.
- **Reserve adequacy** reviews protect financial accuracy.
- Settlement finalizes with **releases, payments, and closure**.
