# 7.1 Claims Overview

## Overview

The **claims function** fulfills the insurer's promise to pay. It is where the product is tested, where the customer experience is defined, and where the insurer's financial results are determined. Good claims handling is **fair, prompt, and accurate**.

## The Role of Claims

| Purpose | Description |
|---|---|
| **Promise fulfillment** | Pay covered losses per the policy |
| **Loss measurement** | Determine amounts, set reserves |
| **Liability determination** | Establish whether the claim is covered |
| **Cost control** | Prevent overpayment and fraud |
| **Recovery** | Subrogation, salvage, reinsurance |
| **Feedback loop** | Data to underwriting, pricing, and risk management |

## Stakeholders

| Stakeholder | Interest |
|---|---|
| **Insured** | Prompt, fair payment of covered loss |
| **Third-party claimant** | Compensation for injury/damage |
| **Producer/broker** | Claims service for clients |
| **Defense counsel** | Legal representation |
| **Adjusters & experts** | Investigation and valuation |
| **Regulators** | Fair claims practices |
| **Reinsurers** | Their share of loss |
| **Shareholders** | Loss ratio and reserving accuracy |

## The Claims Process

```
Notification (FNOL)
      ↓
Coverage verification
      ↓
Investigation
      ↓
Coverage determination
      ↓
Reserving
      ↓
Resolution (settlement or denial)
      ↓
Payment / Recovery
      ↓
File closure & audit
```

| Step | Description |
|---|---|
| **FNOL** | First notice of loss; capture details |
| **Coverage verification** | Policy in force; applicable coverage |
| **Investigation** | Facts, statements, evidence, experts |
| **Coverage determination** | Covered? Excluded? Reservation of rights |
| **Reserving** | Case reserve estimate |
| **Resolution** | Settlement, litigation, or denial |
| **Recovery** | Subrogation, salvage, reinsurance |
| **Closure** | File complete; potential audit |

## Types of Claims

| Type | Characteristics |
|---|---|
| **First-party** | Insured's own loss (property, auto physical damage) |
| **Third-party liability** | Claim against insured (GL, auto liability, professional) |
| **Workers comp** | Statutory benefits to employees |
| **Life/health** | Benefits on death, disability, illness |
| **Large loss** | High-severity; specialized handling |
| **Catastrophe** | Many claims from one event; surge response |
| **Fraud** | Suspected dishonesty; SIU referral |

## Key Performance Indicators (KPIs)

| Metric | Definition |
|---|---|
| **Cycle time** | Time from FNOL to resolution |
| **Claim count & frequency** | Volume trends |
| **Severity** | Average cost per claim |
| **Loss ratio** | Incurred vs. earned premium |
| **Settled vs. reserved** | Accuracy of case reserves |
| **Litigation rate** | % of claims in suit |
| **SIU referrals** | Fraud investigations |
| **Customer satisfaction** | Survey and complaint measures |
| **Aged open claims** | Claims not closed within target |

## Claims Quality

| Principle | Practice |
|---|---|
| **Fair** | Pay what is owed; deny what is not |
| **Prompt** | Meet regulatory and internal timeliness |
| **Accurate** | Correct coverage, valuation, documentation |
| **Empathetic** | Recognize the insured's situation |
| **Transparent** | Clear communication of decisions |

## Summary

- Claims **fulfills the promise** and defines the customer experience.
- The process runs **notification → investigation → coverage → resolution → recovery**.
- **KPIs** (cycle time, severity, loss ratio, reserving accuracy) measure performance.
- Quality means **fair, prompt, accurate, empathetic, and transparent** handling.
- Claims feed **underwriting, pricing, and risk** with data.
