# Limitation Clauses

Limitation clauses cap, narrow, or condition the amount or scope of coverage. They are essential tools for aligning coverage with the risk assessed.

---

## 1. Types of Limitations

| Type | Description |
|------|-------------|
| **Aggregate limit** | Total amount payable for all covered losses in a policy period |
| **Sub-limit** | Separate, lower limit for specific types of loss |
| **Deductible** | Insured's share before insurer pays |
| **Self-insured retention (SIR)** | Insured handles losses up to the retention amount |
| **Waiting period** | Time before coverage begins (e.g., business income) |
| **Per-occurrence cap** | Maximum paid for any single event |
| **Occurrence trigger** | Coverage applies to events during the policy period |
| **Claims-made trigger** | Coverage applies to claims first made during the policy period |

---

## 2. Aggregate Limits

| Element | Description |
|---------|-------------|
| **Purpose** | Caps total exposure for a policy period |
| **General aggregate** | Applies to most covered occurrences |
| **Products / completed operations aggregate** | Separate aggregate for products exposure |
| **Each occurrence** | Standalone limit for a single event |
| **Reinstatement** | Some policies provide full or partial aggregate reinstatement (often at additional premium) |

**Underwriting note:** Confirm the aggregate is adequate for high-frequency risks. Consider whether reinstatement is needed.

---

## 3. Sub-limits

| Sub-limit | Typical Use |
|-----------|-------------|
| **Medical expenses** | Small sub-limit for premises medical payments (e.g., $5,000–$25,000) |
| **Fire legal liability** | Sub-limit for damage to premises rented (e.g., $100,000–$2,000,000) |
| **Personal & advertising injury** | Sometimes sub-limited |
| **Off-premises catering** | Sub-limit for off-premises operations |
| **Parking lots / common areas** | For premises with shared areas |
| **Water damage (property)** | Separate lower limit for water / mold |
| **Wind / hail** | Per-occurrence sub-limit in high-risk zones |
| **Flood** | Sub-limit where flood cover offered |
| **Spoilage** | Sub-limit for contents spoilage (equipment breakdown) |
| **Unauthorized use** | Crime sub-limit for credit / debit card exposure |

**Underwriting note:** Sub-limits align premium with exposure. Document the rationale when imposing sub-limits.

---

## 4. Deductibles

| Type | Description |
|------|-------------|
| **Per-occurrence** | Fixed amount per loss event |
| **Aggregate deductible** | Total deductible for all losses in a period |
| **Percentage deductible** | Percentage of insured value (common for wind/hail, quake, flood) |
| **Disappearing deductible** | Deductible reduces as loss increases |
| **Franchise (threshold)** | Deductible waived once the loss exceeds a threshold |
| **Calendar-year aggregate** | All losses in a year accumulate toward one deductible |

### Deductible Selection Factors

| Factor | Consideration |
|--------|---------------|
| **Affordability** | Insured must be able to absorb the deductible |
| **Premium savings** | Higher deductible usually means lower premium |
| **Frequency vs. severity** | High-frequency / low-severity risks benefit from deductibles |
| **Financial strength** | Weaker insureds may require lower deductibles |
| **Catastrophe exposures** | Percentage deductibles used for cat perils |

---

## 5. Self-Insured Retention (SIR)

| Element | Description |
|---------|-------------|
| **Definition** | Insured is responsible for all defense and indemnity costs up to the SIR |
| **Difference from deductible** | SIR applies before the policy responds at all; deductible often applies within coverage |
| **Defense** | Typically the insured must pay defense costs within the SIR |
| **Administration** | Requires strong claims handling capability |

**Underwriting note:** SIRs require financial verification and confirmed claims administration capability.

---

## 6. Waiting Periods

| Element | Description |
|---------|-------------|
| **Purpose** | Delay coverage onset to reduce small-loss exposure |
| **Business income** | 24–72 hours (or more) typical waiting period |
| **Police / fire department service charge** | May have waiting period |
| **Extended waiting periods** | Reduce premium by eliminating small losses |

---

## 7. Claims-Made Limitations

| Element | Description |
|---------|-------------|
| **Retroactive date** | Claims arising from incidents before this date are not covered |
| **Extended reporting period (tail)** | Coverage for claims after the policy ends |
| **Mini-tail** | Shorter reporting extension (often at no charge) |
| **Full tail** | Long-term reporting extension (purchase option) |
| **Prior acts coverage** | May be negotiated with continuity |

**Underwriting note:** For claims-made forms, always document the retroactive date and advise on tail options.

---

## 8. Defense Cost Considerations

| Element | Description |
|---------|-------------|
| **Inside limits** | Defense costs erode the liability limit |
| **Outside limits** | Defense costs are paid in addition to the limit |
| **Allocated vs. unallocated** | Difference between defense costs assigned to the claim vs. general costs of defense |

**Underwriting note:** Verify how defense costs apply — it affects the effective limit available to the insured.

---

## 9. Layering & Excess

| Element | Description |
|---------|-------------|
| **Primary layer** | First dollar coverage |
| **Excess layers** | Coverage above underlying limits |
| **Follow form** | Excess agrees to follow underlying terms |
| **Drops down** | Only where underlying is exhausted |
| **Vertical vs. horizontal exhaustion** | Order of exhaustion across layers and lines |

**Underwriting note:** Confirm attachment points and the basis of exhaustion to avoid coverage gaps.

---

## 10. Underwriting Best Practices

| Practice | Description |
|----------|-------------|
| **Alignment** | Limitations should match the risk profile |
| **Transparency** | Limitations disclosed and understood |
| **Adequacy** | Limits adequate for foreseeable losses |
| **Documentation** | Rationale recorded in the file |
| **Consistency** | Limitations applied consistently within guidelines |
