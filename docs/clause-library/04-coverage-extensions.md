# Coverage Extension Clauses

Coverage extensions broaden the scope of protection within stated parameters. They are valuable tools to meet insured needs while keeping the exposure controlled.

---

## 1. Automatic Coverage Extensions

| Extension | Description | Example |
|-----------|-------------|---------|
| **Automatic cover for new locations** | Newly acquired premises automatically covered for a stated period | 30–90 days |
| **Automatic increase in values** | Values at specific locations automatically increased (e.g., 10–15%) | Seasonal stock increase |
| **Automatic newly acquired vehicles** | Coverage applies to newly purchased vehicles for a stated period | 30 days |
| **Automatic additional insured** | Contractors / owners automatically added as additional insured per written contract | 30–60 days |

### Automatic Cover Terms

| Element | Detail |
|---------|--------|
| **Period** | Usually 30, 60, or 90 days |
| **Limit** | Usually a stated percentage or flat limit |
| **Notification** | Insured must report; otherwise coverage ends |
| **Premium** | Pro-rata premium applies once reported |

**Underwriting note:** Confirm the automatic cover period provides sufficient time for the insured to report changes while limiting unbounded exposure.

## 2. Newly Acquired Locations

| Element | Description |
|---------|-------------|
| **Property** | New buildings / structures automatically covered for 30 days |
| **Eligibility** | Same occupancy and protection class as the insured's main location |
| **Limit** | Usually subject to a cap (e.g., $250,000–$1,000,000) |
| **Extension** | Requires notice and underwriting approval |

---

## 3. Inflation Guard / Indexation

| Element | Description |
|---------|-------------|
| **Purpose** | Keeps replacement cost values in line with inflation |
| **Mechanism** | Limits automatically increase by a set percentage each quarter / policy period |
| **Typical rate** | 2–8% annually depending on construction costs |
| **Effect** | Reduces the risk of coinsurance penalty |

**Underwriting note:** Where inflation guard applies, verify values remain adequate. Consider higher indexation for high-cost construction markets.

---

## 4. Agreed Value / Agreed Amount

| Element | Description |
|---------|-------------|
| **Purpose** | Waives the coinsurance clause |
| **Requirement** | Insured must certify values; insurer approves |
| **Effect** | Losses paid to the agreed limit without coinsurance penalty |
| **Renewal** | Must be re-certified and re-approved each period |
| **Risk** | Under-valuation by the insured shifts risk to the insurer |

**Underwriting note:** Require current replacement cost valuations (e.g., professional appraisal) before agreeing to agreed amount coverage.

## 5. Business Income Extensions

| Extension | Description |
|-----------|-------------|
| **Extended business income** | Coverage continues after repairs (e.g., 30–60 days) |
| **Extra expense** | Costs to continue operations at other premises |
| **Interruption by civil authority** | Loss of income from government-ordered access prohibition |
| **Dependent properties** | Loss due to damage to key suppliers / customers |
| **Lease / rental value** | Loss of rental income |

---

## 6. Personal Property Extensions

| Extension | Description |
|-----------|-------------|
| **Property in transit** | Goods in transit up to a stated limit |
| **Off-premises property** | Personal property away from the described premises |
| **Property of others** | In the insured's care, custody, or control |
| **Valuable papers & records** | Cost to reconstruct lost records |
| **Trees, shrubs, plants** | Landscape coverage (often sub-limited) |
| **Debris removal** | Additional expense to clear debris after a covered loss |
| **Pollutant cleanup** | Limited on-premises cleanup following a covered cause |

---

## 7. Liability Extensions

| Extension | Description |
|-----------|-------------|
| **Additional insured status** | Covers third parties required by contract |
| **Blanket additional insured** | Automatic additional insured when contract requires |
| **Hired & non-owned auto** | Liability for vehicles not owned by the insured |
| **Employee benefits liability** | Errors in administering benefit plans |
| **Worldwide products** | Products liability for operations outside the home territory |
| **Volunteer workers** | Cover volunteers as insureds |
| **Emergency medical payments** | Immediate medical care without admission of liability |
| **Defense outside limits** | Defense costs not eroding the policy limit |

---

## 8. Crime & Fidelity Extensions

| Extension | Description |
|-----------|-------------|
| **Employee dishonesty** | Loss from employee's dishonest acts |
| **Money & securities** | Loss of money / securities |
| **Forgery / alteration** | Loss from forged or altered instruments |
| **Computer fraud** | Loss from unauthorized computer use |
| **Social engineering** | Fraudulent transfer instructions (often separate) |

---

## 9. Extension Conditions & Limits

| Practice | Description |
|----------|-------------|
| **Cap each extension** | Every extension carries its own sub-limit |
| **Time limits** | Automatic extensions have fixed durations |
| **Notification** | Insured must report within the period |
| **Eligibility** | Extensions apply to eligible risks only |
| **Premium** | Some extensions at additional premium |
| **Documentation** | Record which extensions apply and why |

---

## 10. Underwriting Best Practices

| Practice | Description |
|----------|-------------|
| **Match needs** | Offer extensions that address identified exposures |
| **Control scope** | Use caps and sub-limits to manage aggregation |
| **Verify** | Confirm protective measures required by extensions |
| **Disclose** | Clearly document extensions in the schedule |
| **Review** | Re-assess extensions at each renewal |
