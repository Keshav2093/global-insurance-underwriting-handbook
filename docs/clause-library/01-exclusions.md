# Exclusion Clauses

Exclusions remove specific perils, losses, or risks from coverage. Review carefully at underwriting to ensure the exclusion is clear, enforceable, and meets the risk assessment.

---

## 1. Standard Exclusions (Property)

| Exclusion | Purpose / Effect |
|-----------|------------------|
| **Flood** | Excludes surface water, flood, tidal water, overflow of water bodies |
| **Earthquake** | Excludes earth movement, seismic activity, tremor |
| **Wind / hail in coastal zones** | May be excluded or sub-limited in high-risk territories |
| **Landslide / sinkhole** | Excludes earth movement and collapse of land |
| **Nuclear** | Excludes nuclear reaction, radiation, contamination |
| **War / terrorism** | Excludes declared/undeclared war and (often separately) terrorism |
| **Water damage** | Excludes leakage unless specifically covered |
| **Wear & tear** | Excludes gradual deterioration (lack of fortuity) |
| **Inherent vice** | Excludes losses arising from the nature of the property |
| **Government action** | Excludes seizure, confiscation, destruction by public authority |

---

## 2. Standard Exclusions (Liability)

| Exclusion | Purpose / Effect |
|-----------|------------------|
| **Expected / intended injury** | No coverage for intentional acts |
| **Contractual liability** | Liabilities assumed by contract not covered (unless insured contract) |
| **Pollution** | Excludes pollution-related bodily injury / property damage |
| **Asbestos** | Excludes losses arising from asbestos exposure |
| **Products recall** | No coverage for costs to recall defective products |
| **Employer's liability** | Handled under workers compensation, not CGL |
| **Automobile liability** | Handled under auto policies |
| **Aircraft / watercraft** | Excluded from premises liability operations |
| **Workers compensation** | No CGL coverage for employer obligations |
| **Damage to insured's work** | The insured's own defective work product not covered |
| **Damage to impaired property** | Property not physically injured but diminished in value |
| **Professional services** | Excludes professional liability (E&O) |

---

## 3. Pollution Exclusion

| Element | Description |
|---------|-------------|
| **What it excludes** | Bodily injury or property damage arising from actual, alleged, or threatened discharge of pollutants |
| **Scope** | On-site, off-site, and disposal operations |
| **Pollutants defined** | Smoke, vapor, soot, fumes, acids, alkalis, chemicals, waste |
| **Clarifications** | Some versions allow host-liquor liability, building heating smoke, etc. |
| **Alternative** | Separate pollution liability / environmental policy |

**Underwriting note:** For businesses with pollution exposure, confirm the form is appropriate and consider the need for dedicated pollution coverage or buy-back.

---

## 4. Cyber Exclusion

| Element | Description |
|---------|-------------|
| **What it excludes** | Losses arising from electronic data compromise, computer attacks, hacking |
| **Coverage trigger** | Data breach, ransomware, business interruption from cyber event |
| **Interaction** | Clarifies property and CGL forms do not respond to cyber losses |
| **Alternative** | Standalone cyber insurance policy |

**Underwriting note:** If the insured has cyber exposure, confirm a standalone cyber policy is bound before excluding cyber from the package.

---

## 5. Asbestos Exclusion

| Element | Description |
|---------|-------------|
| **What it excludes** | Bodily injury or property damage arising from asbestos or asbestosis |
| **Materials** | Insulation, fireproofing, flooring, ceiling tiles |
| **Coverage trigger** | Any exposure, regardless of when it occurred |
| **Alternative** | Specialized environmental / asbestos liability programs |

**Underwriting note:** Apply for any insured with construction / demolition / renovation exposure that may disturb asbestos.

---

## 6. War & Terrorism

| Element | Description |
|---------|-------------|
| **War** | Excludes declared and undeclared war, insurrection, rebellion, revolution |
| **Terrorism** | Often a separate exclusion or endorsement |
| **TRIA** | U.S. federal backstop for certified acts (with certification dollar thresholds) |
| **Standalone** | Standalone terrorism coverage available where needed |

**Underwriting note:** Confirm the insured's terrorism coverage requirements and assess whether to offer standalone terrorism coverage.

---

## 7. Aviation & Watercraft

| Element | Description |
|---------|-------------|
| **Aircraft** | Excludes aircraft liability exposure |
| **Watercraft** | Excludes owned / operated watercraft (except small craft may be covered) |
| **Alternative** | Specialized aviation / marine policies |

**Underwriting note:** Any aviation / marine exposure requires separate review and dedicated facility.

---

## 8. Other Property Exclusions

| Clause | Description |
|--------|-------------|
| **Fungi / mold** | Excludes loss from mold, fungus, or bacteria |
| **Virus / pandemic** | Excludes loss from virus, bacteria, communicable disease |
| **Insect / vermin** | Excludes infestation damage |
| **Smoke (agricultural)** | Excludes smoke from agricultural operations |
| **Ordinance / law** | Building codes not covered without endorsement |
| **Collapse** | Not covered unless due to specified causes (unless endorsement) |
| **Utility services** | Off-premises utility disruption not covered (unless endorsement) |
| **Employee dishonesty** | Excluded from property; handled under crime coverage |
| **Money / securities** | Excluded; handled under crime coverage |
| **Accounts receivable / valuable papers** | Excluded; handled under inland marine |

---

## 9. Underwriting Best Practices

| Practice | Description |
|----------|-------------|
| **Confirm coverage intent** | Exclusions must align with the risk assessment |
| **Explain to insured** | Major exclusions disclosed and understood |
| **Document decision** | Note why exclusion applied / not applied |
| **Consider alternatives** | Buy-backs or standalone policies where needed |
| **Check jurisdiction** | Some exclusions unenforceable in certain states |
| **Review endorsements** | Confirm related endorsements completed |
