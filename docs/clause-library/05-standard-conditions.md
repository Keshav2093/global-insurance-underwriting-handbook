# Standard Policy Conditions

Standard policy conditions appear across most property and casualty policies. They define the obligations of both parties and the framework within which coverage operates.

---

## 1. Cancellation

| Element | Description |
|---------|-------------|
| **Insurer's right** | Cancel with advance notice (typically 30–60 days) |
| **Insured's right** | Cancel at any time; return premium at short-rate |
| **Statutory restrictions** | Mid-term cancellation reasons limited in many states (especially personal lines) |
| **Non-renewal** | Separate notice requirements (often 45–60 days) |
| **Applies to** | All policies unless stated otherwise |

### Notice Requirements by Type

| Action | Typical Notice |
|--------|----------------|
| Cancellation for non-payment | 10–15 days |
| Cancellation for underwriting reasons | 30–60 days |
| Non-renewal | 45–60 days |
| Conditional renewal | Same as non-renewal |

---

## 2. Concealment, Misrepresentation or Fraud

| Element | Description |
|---------|-------------|
| **Concealment** | Failure to disclose a material fact |
| **Misrepresentation** | False statement of a material fact |
| **Fraud** | Intentional deception to obtain coverage or payment |
| **Effect** | Policy is void from inception |
| **Applies to claims** | Fraudulent claims void the claim and may void the policy |

**Underwriting note:** Materiality is judged by whether the insurer would have acted differently had it known the truth.

---

## 3. Examination of Books & Records

| Element | Description |
|---------|-------------|
| **Requirement** | Insured allows examination of records |
| **Applies to** | Premium audit (payroll, receipts), loss adjustment, and policy investigation |
| **Cost** | Usually at the insurer's expense |
| **Time** | During the policy period and after cancellation (for audit) |

---

## 4. Duties After Loss (Property)

| Condition | Description |
|-----------|-------------|
| **Give prompt notice** | Notify insurer as soon as practicable |
| **Protect property** | Take reasonable steps to prevent further damage |
| **Inventory** | Provide detailed inventory of damaged property |
| **Cooperate** | Assist in the investigation and adjustment |
| **Proof of loss** | Submit signed, sworn proof of loss within a stated period (e.g., 60 days) |
| **Allow inspection** | Show damaged property |
| **Submit to examination** | Answer questions under oath |

---

## 5. Duties After Occurrence (Liability)

| Condition | Description |
|-----------|-------------|
| **Prompt notice** | Notify of occurrence / claim / suit as soon as practicable |
| **Provide details** | Names, times, places, witnesses |
| **Forward documents** | Any demands, summonses, or legal papers |
| **Cooperate** | Assist in investigation, settlement, and defense |
| **No voluntary payments** | Insured may not admit liability or pay without consent |

---

## 6. Appraisal (Property)

| Element | Description |
|---------|-------------|
| **Trigger** | Disagreement on the amount of loss or value of property |
| **Process** | Each party selects an appraiser; appraisers select an umpire |
| **Award** | Agreement by any two binds the insurer and insured |
| **Cost** | Each side pays its own appraiser; umpire costs shared |

---

## 7. Subrogation

| Element | Description |
|---------|-------------|
| **Definition** | Insurer's right to step into the insured's position to recover from responsible third parties |
| **Insured's duty** | Cooperate, preserve rights, do not impair subrogation |
| **Waiver** | May be waived where contract requires (e.g., construction contracts) |

---

## 8. Legal Action Against Us

| Element | Description |
|---------|-------------|
| **Requirement** | All policy conditions must be fulfilled |
| **Time limit** | Action must begin within the statute of limitations period |
| **No suit until coverage decided** | Insured cannot sue before the insurer performs its obligations |

---

## 9. Transfer of Rights / Assignment

| Element | Description |
|---------|-------------|
| **General rule** | Policy cannot be assigned without the insurer's written consent |
| **Exception** | Assignment to heirs on death of the named insured |
| **Purpose** | Prevents transfer of policy to an unknown risk |

---

## 10. Joint or Separate Interests / Other Insureds

| Condition | Description |
|-----------|-------------|
| **Joint insureds** | Each insured has rights under the policy |
| **Separate application** | Coverage applies separately to each insured |
| **Conduct of one** | Fraud / misrepresentation by one insured may not prejudice others (varies) |
| **Third-party claims** | An insured may not claim against another insured (exclusions apply) |

---

## 11. Bankruptcy / Insolvency

| Element | Description |
|---------|-------------|
| **Effect** | Does not relieve the insurer of obligations |
| **Liability positions** | An insured's bankruptcy does not reduce available limits |
| **Difference** | Insurer insolvency is addressed through guaranty funds |

---

## 12. Premium Audit

| Element | Description |
|---------|-------------|
| **Basis** | Premiums based on estimated exposures are audited at expiration |
| **Adjustment** | Additional premium or return premium follows the audit |
| **Documents** | Payroll records, sales records, vehicle schedules |
| **Deadline** | Insured must provide records within a stated period |

---

## 13. Territory & Jurisdiction

| Element | Description |
|---------|-------------|
| **Policy territory** | Where coverage applies (e.g., U.S., Canada, worldwide for products) |
| **Jurisdiction** | Laws governing the policy (often state where insured is located) |
| **Extraterritorial application** | Confirm coverage for operations in other jurisdictions |

---

## 14. Severability of Interests

| Element | Description |
|---------|-------------|
| **Purpose** | Each insured's coverage considered separately |
| **Application** | Breach of condition by one insured does not necessarily impair others |
| **Boundary** | Misrepresentation in the application may still void the whole policy |

---

## 15. Insuring Agreement & Form

| Element | Description |
|---------|-------------|
| **Declarations** | Identifies the insured, coverage, limits, premium |
| **Insuring agreement** | Grants coverage per stated terms |
| **Definitions** | Define key terms used in the policy |
| **Conditions** | Specify obligations and framework |
| **Endorsements** | Modify the base policy — read last in case of conflict |
| **Exclusions** | Remove perils / losses |

### Policy Reading Order

| Priority | Document |
|----------|----------|
| 1 | Endorsements (latest first) |
| 2 | Declarations |
| 3 | Policy conditions |
| 4 | Insuring agreements |
| 5 | Definitions |
| 6 | Exclusions |

---

## 16. Underwriting Best Practices

| Practice | Description |
|----------|-------------|
| **Confirm understanding** | Conditions disclosed and understood |
| **Verify premiums** | Audit clauses applied consistently |
| **Compliance** | Cancellation / notice requirements met |
| **Documentation** | Basis of coverage and conditions recorded |
| **Timeliness** | Renewal and notice deadlines respected |
