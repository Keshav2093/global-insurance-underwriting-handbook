# 4.2 Information Sources

## Overview

Underwriting decisions are only as good as the information supporting them. The underwriter gathers data from the **submission**, **third-party databases**, **inspections**, and **company records**, then validates and interprets it.

This chapter catalogs the main information sources and the questions each answers.

## Core Information Sources

| Source | Information Provided |
|---|---|
| **Application** | Risk description, coverage requested, values, operations |
| **Loss runs** | Prior claims history (frequency, severity, type) |
| **MVR (Motor Vehicle Report)** | Driver licensing, violations, accidents |
| **CLUE / A-Plus** | Personal/commercial property loss history |
| **Inspections / surveys** | Physical condition, COPE, protection |
| **Financial statements** | Business financial health, payroll, assets |
| **Credit / insurance scores** | Payment and loss-propensity indicators |
| **Public records** | Litigation, liens, judgments, bankruptcy |
| **Prior carrier records** | Coverage history, claims handling, cancellations |
| **Broker/agent reports** | Relationship, knowledge of the insured |

## The Application

The application is the primary document — but only as accurate and complete as the person who completes it.

| Section | Typical Contents |
|---|---|
| **Named insured** | Legal entity, address, ownership |
| **Operations** | Class, products, processes, locations |
| **Coverage requested** | Limits, forms, deductibles |
| **Exposure data** | Values, payroll, receipts, vehicles, units |
| **Prior losses** | Description and history |
| **Financial data** | For commercial risks |
| **Signatures** | Application is part of the policy basis |

### Validating the Application

- Is the information **internally consistent**?
- Does the **occupancy** match the coverage requested?
- Are **values** realistic (not under/overstated)?
- Was the application **signed and dated**?

Where an application is part of the policy, **misrepresentation** can void coverage. Underwriters must ensure the basis of the contract is accurate.

## Loss Runs

**Loss runs** are the prior claims record. They reveal:

- **Frequency** — how often claims occur.
- **Severity** — average and maximum paid/incurred.
- **Cause patterns** — theft, fire, liability, WC.
- **Trend** — improving or deteriorating.

### Loss Run Details

| Field | Meaning |
|---|---|
| Policy period | The year of coverage |
| Claim number | Identity |
| Date of loss | When it occurred |
| Cause / description | What happened |
| Paid amount | What has been paid |
| Incurred amount | Paid + reserves |
| Status | Open, closed, reopened |
| Months of disability (WC) | Duration |
| Subrogation recovered | Recoveries |

### Loss Run Analysis

- Compare **loss ratio** (incurred ÷ premium) to expected by line.
- Review **large losses** individually; avoid over-reacting to one-off events.
- Watch for **small claims frequency** — a behavioral warning.
- Consider **reserves** — high open reserves indicate active claims.

## Motor Vehicle Reports (MVR)

MVRs provide the driving record:

| Data | Use |
|---|---|
| Violations | Speeding, DUI, reckless driving |
| Accidents | At-fault and not-at-fault |
| License status | Valid, suspended, revoked |
| CDL | Commercial driver's license status |

### MVR Underwriting

- **Points systems** — assign severity to violations and accidents.
- **DUI/CUI** — significant surcharge or declination.
- **Multiple violations** — indicates risky driving behavior.
- **Unlicensed drivers** — auto coverage generally excluded.

MVR use is regulated: **adverse action** notices are required where MVR affects the decision (US Fair Credit Reporting Act and state laws).

## Claim History Databases

| Database | Contents |
|---|---|
| **CLUE (Comprehensive Loss Underwriting Exchange)** | Personal and commercial property/auto claims (LexisNexis) |
| **A-PLUS** | Auto and property loss database (Verisk) |
| **Index systems** | Insurance claims history (ISO index) |
| **Medical information databases** | Life/health history (MIB, medical information bureau) |

These databases identify **claims not disclosed** in the application — a key anti-fraud and accuracy tool.

## Inspections and Surveys

Risk inspections provide **physical evidence**:

| Type | Purpose |
|---|---|
| **Photo inspections** | Condition, occupancy, exterior |
| **Drive-by** | Neighborhood, property condition |
| **Full survey** | COPE, protection, construction, occupancy details |
| **Engineer survey** | Complex property, machinery, process hazards |
| **Liability inspection** | Premises condition, hazards, exposures |

### When Inspections Are Required

- New business above a value threshold.
- Older or high-value dwellings.
- Commercial risks with complex operations.
- Vacant or special occupancies.
- Following large losses (to verify controls).

## Financial Data

For commercial lines and high-value personal, financials matter:

| Document | Use |
|---|---|
| **Financial statements** | Profitability, solvency, net worth |
| **Tax returns** | Income verification (personal and business) |
| **Payroll records** | WC exposure verification |
| **Bank statements** | Cash flow, creditworthiness |
| **Budget/forecast** | Forward-looking assessment |

Financial strength affects terms and pricing: financially distressed insureds may cut maintenance, under-insure, or commit fraud.

## Credit and Insurance Scores

- **Credit-based insurance scores** — proprietary scores used in personal auto and property to predict loss propensity (where legally permitted).
- **Payment history** — consistent premium payment correlates with lower loss frequency.
- **Regulatory constraints** — some states and countries restrict credit use (e.g., some US states ban or limit; UK insurance pricing rules cap the "loyalty penalty").

The underwriter must know **what data is permissible** in their jurisdiction and **when adverse action notices** are required.

## Public Records and Litigation

| Data | Source |
|---|---|
| **Lawsuits** | Court records, judgment searches |
| **Liens** | Property liens, tax liens |
| **Bankruptcy** | Bankruptcy filings |
| **Licenses** | Professional licenses, complaints |
| **OSHA/DOT** | Workplace safety, transportation violations |
| **Regulatory actions** | Fines, consent orders |

Public records identify **litigation-prone** insureds, **fraud risk**, and **compliance problems**.

## Prior Carrier and Broker Records

- **Prior policies** — coverage history, gaps, cancellations.
- **Cancellation reasons** — for cause, for underwriting, for non-payment.
- **Claims handling** — litigated claims, coverage disputes.
- **Broker relationship** — track record of the producer, loss ratio, professionalism.

## Privacy and Compliance

| Jurisdiction | Key Rules |
|---|---|
| **US** | FCRA (consumer reports, adverse action), GLBA (privacy), HIPAA (medical), state laws |
| **UK** | GDPR/UK GDPR (data protection), FCA (fair treatment, pricing rules) |
| **General** | Data minimization, consent, retention, security |

The underwriter must understand **what can be collected, how it can be used, and what disclosures are required** when adverse decisions are based on third-party data.

## Information Quality and Reliability

| Criterion | Question |
|---|---|
| **Accuracy** | Is the data verifiable from sources? |
| **Completeness** | Are gaps in the submission filled? |
| **Timeliness** | Is the data current? |
| **Relevance** | Does it bear on the risk? |
| **Permissibility** | Is collection/use legal? |

When information is missing or unreliable, the underwriter must **request more data** or make a **conservative assumption** — never guess.

## Summary

- The application, loss runs, MVR, claim databases, inspections, financials, credit, and public records are the core data sources.
- Each answers a different question about the risk.
- **Validation and consistency checks** guard against errors and fraud.
- **Privacy and adverse action rules** govern data use.
- **Information quality** determines the quality of the underwriting decision.
