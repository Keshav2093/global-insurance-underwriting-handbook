# 5.8 Reinsurance

## Overview

**Reinsurance** is insurance for insurers — the transfer of risk (and premium) from a primary insurer (the **cedent**) to a reinsurer. Reinsurance protects against:

- **Individual large losses** — single risk severity.
- **Aggregate catastrophe losses** — many risks in one event.
- **Volume of risk** — expanding capacity.
- **Volatility** — smoothing results.

## Why Reinsurance

| Purpose | Example |
|---|---|
| **Capacity** | Enable writing limits beyond own resources |
| **Catastrophe protection** | Hurricane, earthquake, flood events |
| **Earnings stability** | Smooth large single losses |
| **Capital management** | Reduce required solvency capital |
| **Portfolio transfer** | Exit a line or territory |
| **Expertise** | Reinsurer provides underwriting insight |

## Types of Reinsurance

### 1. Proportional (Pro Rata)

| Structure | Description |
|---|---|
| **Quota share (QS)** | Fixed % of every risk ceded; premium and losses shared in same % |
| **Surplus share** | Cede only risk above retention; proportional per risk |

**Features:**

- Reinsurer shares premium, losses, and expenses proportionally.
- Ceding commission compensates the cedent for acquisition and admin.
- Used for capacity and portfolio sharing.

### 2. Non-Proportional (Excess of Loss)

| Structure | Description |
|---|---|
| **Per risk XL** | Reinsurer pays losses per risk above a retention |
| **Catastrophe XL (Cat)** | Reinsurer pays losses from one event above an aggregate retention |
| **Stop loss** | Protects the annual aggregate loss ratio |

**Features:**

- Premium is independent of individual risk premium.
- Uses **loss rate** or **burning cost** pricing.
- Retention = company's retained loss per event/risk.

## Reinsurance Pricing

### Proportional Pricing

```
Reinsurer's premium = Ceded % × Gross Premium (minus ceding commission)
```

### Non-Proportional Pricing

```
Burning cost = Expected losses to the layer ÷ Premium input

Rate on Line (ROL) = Layer Limit ÷ Layer Premium × 100%

Technical price = Expected loss cost + LAE + expense + profit loading
```

### Pricing Components

| Component | Description |
|---|---|
| **Expected loss cost** | Historical loss experience, trended, projected |
| **Burning cost** | Simple average of past losses to the layer |
| **Rate on line (ROL)** | Premium as % of limit |
| **Exposure rating** | Based on exposure data (e.g., PML) |
| **Experience rating** | Cedent's own claims experience |
| **Expense loading** | Acquisition, admin, brokerage |
| **Risk/return loading** | CAT models, capital cost |

## The Retention Decision

Choosing the **retention** (what the cedent keeps) balances:

| Factor | Lower Retention | Higher Retention |
|---|---|---|
| **Premium cost** | Higher reinsurance cost | Lower reinsurance cost |
| **Earnings volatility** | Lower volatility | Higher volatility |
| **Capital requirement** | Lower required capital | Higher required capital |
| **Frequency of claims to layer** | More frequent recovery | Less frequent recovery |

The optimal retention aligns with **capital tolerance** and **earnings targets**.

## Facultative vs. Treaty

| Type | Description |
|---|---|
| **Facultative** | Individual risk-by-risk reinsurance; full underwriting each time |
| **Treaty** | Automatic coverage for a defined class of risks; bordereau reporting |

Treaties are cheaper and more seamless; facultative is used for large or unusual risks outside the treaty.

## Reinsurance Program Design

A typical commercial program combines layers:

```
Layer 3: Catastrophe excess (e.g., $100M xs $100M)
Layer 2: Mid excess (e.g., $50M xs $50M)
Layer 1: Working / per risk XL (e.g., $10M xs $5M)
Retention: Net retained by cedent (e.g., $5M)
```

## Reinsurance and Underwriting

- Underwriters must know the **reinsurance program**: what is retained, what is ceded.
- **Facultative** decisions require underwriter input on each risk.
- **Ceding limits** and **recovery terms** vary by treaty.
- **Credit risk** — reinsurance recoverables are assets; they must be secure.

## Reinsurance Administration

| Activity | Purpose |
|---|---|
| **Bordereau** | Monthly premium/loss reporting per treaty |
| **Cash calls** | Quick recovery of large claims |
| **Accounts** | Premium, claims, commissions, profit commission |
| **Audit** | Reinsurer audits cedent records; rights of access |

## Regulation and Security

- **Trust funds** — reinsurer collateral for US cedents.
- **Collateral requirements** — letters of credit, funds withheld.
- **Licensing** — admitted vs. non-admitted reinsurers.
- **IFRS 17 / Solvency II** — reinsurance assets and contract boundaries.
- **Credit for reinsurance** — regulator recognition only if the reinsurer is secure.

## Emerging Issues

| Issue | Consideration |
|---|---|
| **Cyber aggregation** | Systemic, correlated losses; model uncertainty |
| **Secondary perils** | Severe convective storms, wildfire — frequency rising |
| **Retrocession** | Reinsurers buying reinsurance; market capacity |
| **ILS (insurance-linked securities)** | Cat bonds, collateralized reinsurance — capital market capacity |
| **Climate stress testing** | Model scenarios beyond historical |

## Summary

- Reinsurance transfers **risk and premium** for capacity, catastrophe, and stability.
- **Proportional** shares risk in %; **non-proportional** responds above retentions.
- Pricing uses **burning cost, exposure, and experience** methods with expense and capital loadings.
- **Retention levels** balance cost against volatility and capital.
- Underwriters must know the net position and the treaty terms.
- **Security and collateral** protect recoverables.
