# 5.6 Rating by Line

## Overview

Each line of business has its own **rating structure and exposure base**. This chapter summarizes the rating approach for each of the principal lines covered in Volumes 2 and 3.

## Personal Auto

```
Premium = (Liability + Collision + Comprehensive + UM/UIM + Medical) × Territory × Vehicle × Driver Factors
```

| Component | Exposure Base | Main Factors |
|---|---|---|
| **Liability** | Car year | Territory, driver record, age, mileage |
| **Collision** | Car year | Vehicle value, symbol, deductible |
| **Comprehensive** | Car year | Vehicle, territory (theft), deductible |
| **UM/UIM** | Car year | Limits, state |
| **Medical/PIP** | Per person | State, limits |

- **Vehicle symbol** reflects cost to repair/replace.
- **Telematics** adds actual driving data.

## Homeowners

```
Premium = Base Rate × Construction × Protection × Territory × Coverage Limits × Deductible
```

| Factor | Description |
|---|---|
| **Dwelling limit** | Reconstruction cost, not market value |
| **Protection class** | Fire district rating |
| **Territory** | Hail, wind, crime, wildfire |
| **Construction** | Frame vs. masonry vs. fire-resistive |
| **Deductible** | Percentage or flat |
| **Endorsements** | Contents, replacement cost, water backup |

## Commercial Property

```
Premium = (Building Rate × Building Value + Contents Rate × Contents Value) × COPE Factors
```

| Factor | Description |
|---|---|
| **COPE** | Construction, occupancy, protection, exposure |
| **Coinsurance** | Penalty if insured below stated % of value |
| **SOV** | Statement of values per location |
| **BI** | Business income exposure: gross earnings × period |
| **Deductibles** | Time (BI), flat, percentage |

## Commercial General Liability

```
Premium = Class Rate × Exposure Base (per $1,000 receipts or $100 payroll)
```

| Component | Basis |
|---|---|
| **Premises/operations** | Receipts, payroll, area |
| **Products/completed ops** | Gross sales |
| **Occurrence vs. claims-made** | Different coverage periods, different rating |
| **ILF** | Increased limits factor |
| **Per-occurrence aggregate** | Exposure measure |

## Commercial Auto

```
Premium = (Liability Symbol × Radius × IA) + (Physical Damage Symbol × Vehicle Value)
```

| Factor | Description |
|---|---|
| **Symbol** | Vehicle cost group |
| **Radius** | Mileage/territory of operation |
| **IA (interstate authority)** | Operating scope |
| **Fleet size** | Experience becomes credible |
| **MVR** | Driver risk |

## Workers Compensation

```
Premium = (Payroll ÷ 100) × Class Rate × Experience Mod × Premium Discount
```

| Element | Description |
|---|---|
| **Class code** | Occupation; highest-paying principal class governs where allowed |
| **Experience mod (E-mod)** | Credibility-weighted loss history |
| **Premium discount** | Volume-based expense reduction |
| **Deductible programs** | Large account retention |
| **State** | Benefit levels, rates, classifications |

## Business Owners Policy (BOP)

- **Package credit** — property + liability bundled.
- Simplified rating: size, occupancy, territory, protection.
- Eligibility rules (occupancy, size, limits) restrict qualifying risks.

## Life / Health

| Product | Premium Basis |
|---|---|
| **Term life** | Age, sex, health class, smoker status, amount |
| **Whole life** | Same + cash value and dividend assumptions |
| **Annuities** | Age, sex, interest assumptions |
| **Disability** | Occupation, income, elimination period, benefit period |
| **Health/medical** | Age, geography, plan design, risk adjustment |

Life pricing uses **mortality tables**, **interest**, and **expenses** (see Volume 2 chapter 6).

## Package and Multi-Line Pricing

- **Package discount** reflects expense savings (single policy, single premium).
- Must be justified by **actual cost savings**, not across-the-board subsidy.
- Multi-line accounts are underwritten **line-by-line** first; the package credit is applied last.

## Specialty Lines

| Line | Rating Basis |
|---|---|
| **Inland marine** | Equipment values, transit exposure, coverage limits |
| **Ocean marine** | Vessel value, hull rate, cargo, P&I |
| **Aviation** | Aircraft value, pilot, use, territory |
| **Surety** | Contract size, financial strength, capacity |
| **Cyber** | Revenue, records, industry, security controls, limits |
| **D&O** | Assets, market cap, class D claims, limits |
| **Professional liability** | Revenue, headcount, discipline, limits |
| **Environmental** | Site type, operations, coverages |

## Summary

- **Exposure bases** differ by line: values, receipts, payroll, car years, headcount.
- **Rating structures** are built from base rates × classification factors × limit/deductible adjustments.
- **Experience** (E-mod, fleet, schedule) adjusts for account-specific history.
- **Packages** discount only justified expense savings.
- **Specialty lines** use bespoke exposure measures and technical factors.
